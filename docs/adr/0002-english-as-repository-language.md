# 0002. English as the repository language

- **Status:** Accepted
- **Date:** 2026-11-23

## Context

The author is a Brazilian Computer Science student. The project is also a portfolio piece, and the code, documentation and history may be read by recruiters and developers who do not speak Portuguese. Mixing languages in code (for example `GetCampanha`) is hard to read and to keep consistent.

## Decision

Use English for everything in the repository: code (classes, variables, database tables and columns), commit messages, branch names, pull requests and documentation.

## Consequences

- Names follow the conventions of the .NET and React ecosystems, which are in English.
- The project can be shared with an international audience.
- User-facing text in the application can still be in Portuguese, or be translated later.
